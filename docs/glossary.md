# Глоссарий

> **Doc sync:** 2026-09-05.

Термины, которые повторяются во всех документах и в коде. Если слово ниже
встретилось в чужом коммите или в задаче — здесь его точное значение
именно в этом проекте, а не вообще.

## Учёба

**Режим учёбы (mode)** — один из четырёх способов заниматься:
`situational`, `flashcards`, `mcq`, `tasks`. Идентификатор режима
определяет, где лежит контент. См. [features.md](features.md) §3.

**Предмет (subject)** — папка в `study_materials/` плюс id в
`SUBJECT_IDS`. Появляется в меню сам, как только у него есть непустой
контент хотя бы одного режима.

**Освоено (mastered)** — считается по-разному в каждом режиме: streak ≥ 3
у ситуационных, repetitions ≥ 3 у карточек, хотя бы один верный ответ у
MCQ, `succeeded = 1` у задач. Именно это заполняет 🟩-квадраты на экране
прогресса.

**Хеш контента** — стабильный id элемента без отдельной таблицы контента:
`md5(термин)[:8]` для официальной карточки, `u{card_id:07x}` для своей,
`task-NN` или `u{db_id:07x}` для задачи. **Правка термина меняет хеш и
обнуляет прогресс** — правка определения безопасна.

**SM-2** — алгоритм интервального повторения SuperMemo-2 для флэш-карт.
**EF (ease factor)** — множитель интервала конкретной карточки: старт 2.5,
пол 1.3 (`EF_FLOOR`). Чем ниже EF, тем чаще карточка возвращается.

**Text-only задача** — задача без картинки: условие целиком в поле
`problem` JSON-файла, `text_only: true`.

## Геймификация

**Монеты (🪙)** — внутренняя валюта. Зарабатываются учёбой, тратятся на
питомца и заморозку стрика. Реальной ценности не имеют.

**Стрик (streak)** — дни подряд с учёбой. Считается ночью в **локальном**
часовом поясе пользователя (23:58–23:59), не в серверном.

**Заморозка стрика (freeze)** — покупка за 500/750/1000 🪙, которая
позволяет пропустить один день. Не чаще одной в 7 дней.

**Ачивка** — одно из 10 достижений из `achievements.json`. Выдаётся один
раз, повторно не переигрывается.

**XP и уровень питомца** — 1 XP за минуту учёбы,
`level = floor(sqrt(xp / 10)) + 1`. Уровень открывает предметы
кастомизации, монеты позволяют их купить.

**Эмоция питомца** — `neutral` / `joy` / `sad`. **Не хранится в БД**:
выводится в момент рендера из состояния пользователя
(`services.derive_emotion`).

## Лидерборд

**Компонент счёта** — одно из четырёх слагаемых недельной суммы:
`time_pts`, `task_pts`, `quiz_pts`, `card_pts`.

**Дневной кап (cap)** — предел начислений за сутки по каждому компоненту
(240 минут, 5 задач, 25 верных квизов, 8 карточек). Сверх капа действие
засчитывается, но очков не даёт.

**Тир (tier)** — ступень кусочно-линейного начисления за время: первые
60 минут по 1.00 pts, следующие 60 по 0.75 и так далее.

**Множитель стрика** — ×1.00 … ×1.20 по длине стрика. **Не хранится**:
применяется при чтении, поэтому вся неделя пересчитывается задним числом,
когда стрик растёт.

**Сегмент** — `newbie` (зарегистрирован меньше 7 дней назад) или `main`.
Роутинг автоматический, кнопок нет.

**Rollover** — еженедельная выдача наград, вторник 00:00 UTC. Не путать с
границей недели для набора очков: она в локальном времени пользователя
(ISO-неделя). Почему так — [architecture.md](architecture.md).

**Бэдж (badge)** — недельная награда: `top_1`, `top_2`, `top_3`,
`breakthrough` (1-е место у новичков), `top10_pct_bonus` (служебный, им же
обеспечивается идемпотентность монетного бонуса).

## Техническое

**FSM** — конечный автомат aiogram: в каком мастере находится пользователь
(таймер, квиз, добавление друга). Хранится в SQLite, поэтому переживает
рестарт.

**Reconcile** — разбор таймеров, оставшихся в FSM после рестарта:
досчитанные закрываются, недосчитанные возобновляются.
`source=reconcile` в событии `session_completed` — признак именно такой
сессии.

**Репозиторий** — класс в `repository.py`, единственное место, где живёт
SQL для своей таблицы.

**Событие (event)** — строка в append-only таблице `events`. Пишется
через `EventRepository.log`, который **никогда не бросает исключение**.

**Две метрики активности** — `activity_progress` (по progress-таблицам) и
`activity_events` (по таблице `events`). Дают разные числа; при разговоре
о DAU всегда уточняйте, какая имеется в виду.
См. [analytics.md](analytics.md).

**Фичефлаг** — константа, выключающая готовый код из UI. Сейчас их три:
`PLAN_UI_ENABLED`, `PET_CUSTOMIZATION_ENABLED`, `PET_SINGLE_IMAGE_MODE`.
Таблица со значениями — [architecture.md](architecture.md) §«Выключенные
фичи».

**Doc sync** — дата в шапке документа, когда его последний раз сверяли с
кодом. Обновляется вместе с правкой, проверяется
`python scripts/check_docs.py`.

## Исторические имена

Проект переименован из **StudyBuddy** в **Palph** 2026-05-19, но внутренние
имена сохранены ради работающих деплоев: `studybuddy.db` (файл БД),
`studybuddy_bot` (логгер), `studybuddy-{date}.db` (бэкапы),
`studybuddy-bot` (контейнер). Это не опечатки.

Ключ кнопки `kb.quizzes` тоже исторический: кнопка давно называется
«📖 Подготовка».
