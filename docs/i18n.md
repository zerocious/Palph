# Локализация (ru / en)

> **Doc sync:** 2026-09-05 · **443** ключа в каждом бандле, **34** группы,
> 306 ключей реально используются в коде, расхождений между ru и en нет
> (`python scripts/audit_i18n_keys.py`).

## Как это устроено

`i18n.py` — минимальный слой без внешних зависимостей:

```python
from i18n import t, kb_in, all_locale_texts

t("timer.started", "en", duration=25)   # перевод с подстановкой
kb_in("kb.profile")                     # фильтр aiogram по кнопке на обеих локалях
all_locale_texts("kb.profile")          # ["👤 Профиль", "👤 Profile"]
```

- Бандлы — `locales/ru.json` и `locales/en.json`, вложенные словари,
  ключ через точку: `t("start.welcome_new")` → `start` → `welcome_new`.
- Загрузка кешируется (`lru_cache`), поэтому правка JSON требует
  перезапуска бота.
- Фолбэк-цепочка: запрошенная локаль → `ru` → **сам ключ**. Если в чате
  видно `something.like_this` — значит, ключ забыли добавить.
- Подстановка через `str.format(**kwargs)`; при `KeyError` возвращается
  неформатированная строка, а не исключение.

## Локаль пользователя

Хранится в `users.locale` (`ru` / `en`; пустая строка = ещё не выбрана).
Выбирается инлайн-пикером при первом `/start`, меняется в настройках.
В хендлерах локаль всегда берётся явно: `locale = await loc(user_id)`.

При смене языка переустанавливаются и команды в `/`-пикере
(`apply_user_bot_commands` → `commands_for_locale`).

## Группы ключей

`achievements_notify`, `commands`, `common`, `delete_account`, `errors`,
`faq`, `fc`, `flash`, `freeze`, `friends`, `kb`, `lang`, `leaderboard`,
`mcq`, `nav`, `pet`, `plan`, `profile`, `progress`, `quiz`,
`quiz_sections`, `rating`, `reminders`, `settings`, `setup`, `start`,
`study`, `study_modes`, `subjects`, `support`, `task`, `timer`, `tips`,
`user_tasks`.

Особые группы:

| Группа | Роль |
|--------|------|
| `kb` | Тексты reply-кнопок. Хендлеры сравнивают через `kb_in("kb.<id>")`, поэтому кнопка работает на любой локали |
| `subjects`, `study_modes`, `quiz_sections` | Ярлыки по id; резолвятся хелперами `subject_label()`, `study_mode_label()`, `quiz_section_label()` |
| `commands` | Описания команд в `/`-пикере Telegram |
| `faq` | По три ключа на пункт: `btn`, `title`, `body` |

## Как добавить строку

1. Добавить ключ **в обе** локали в `scripts/build_locales.py` (генератор —
   источник истины, `locales/*.json` — сгенерированный артефакт).
2. Перегенерировать:

   ```bash
   python scripts/build_locales.py
   ```

3. Использовать в коде: `t("group.key", locale, param=value)`.
4. Проверить:

   ```bash
   python scripts/audit_i18n_keys.py      # ключи из t() против бандлов
   python -m pytest tests/test_i18n.py -q
   ```

> Историческая ловушка: пересборка бандлов уже дважды роняла ключи,
> добавленные вручную прямо в JSON (коммиты `c696f5f`, `e69d6be`,
> `e321eeb` — «Fix missing i18n keys dropped in locale rebuild»). Отсюда
> правило: правим генератор, а не JSON.

## Не локализовано намеренно

- **Административный контур** — `/help` для админов, `ADMIN_COMMANDS`,
  вывод аналитических команд: только русский. Админ один и он
  русскоязычный; локализация удвоила бы работу без пользы.
- **Уведомление о level-up питомца** собирается в
  `StudyService._notify_level_up` на русском.
- **Ярлыки часовых поясов** (`TZ_PRESETS`): Россия/СНГ — по-русски,
  остальной мир — по-английски, чтобы название города совпадало с тем,
  как его ищут.
- **Учебный контент** — на языке предмета, локали не касаются.
- **Каталог ачивок** — отдельные файлы `achievements.json` (ru) и
  `achievements.en.json` (en), выбирает `load_achievements_catalog`.
- **Советы** — `tips/*.json` (ru) с опциональным переопределением в
  `tips/<locale>/`, см. [content-authoring.md](content-authoring.md).

## Добавление третьего языка

Понадобится: расширить `SUPPORTED_LOCALES` в `i18n.py`, добавить ветку в
`build_locales.py`, положить `achievements.<loc>.json` и, при желании,
`tips/<loc>/`. Дальше всё работает само — код нигде не хардкодит два
языка, кроме пикера при первом `/start`.
