## Поведение в боте

- **Загрузка:** JSON из этой папки через `locale_bot.tip_categories()` — **перечитывается на каждый вызов**, кеша нет, правка файла видна без рестарта. Переводы — `tips/<locale>/` с тем же именем файла. Legacy `.txt` в корне — fallback. (`bot.TIP_CATEGORIES` — снимок RU-каталога на момент импорта, нужен только тестам.)
- **UI:** категории → случайный совет; inline «🔄 Ещё совет», «📋 Все советы» (пагинация), ссылки — URL-кнопки.
- **Контекстный подбор** — при активном таймере приоритет `timer`; если не учился сегодня — `study`/`focus`/`bot`; если есть карточки к повторению — `flashcards`.
- **Cooldown 7 дней** — `user_tips_seen`: недавние `tip_id` исключаются из random/more (если пул исчерпан — показываем снова).
- **Совет дня** — в 🌅 утреннем напоминании; один `tip_id` на календарный день (TZ пользователя). Не увеличивает `total_views`.
- **Геймификация:** +1 🪙 за первый просмотр совета за день; ачивка `10_tips_read` («Любознательный») после 10 просмотров (+30 🪙); событие `tip_viewed`.
- **Что считается просмотром:** открытие категории и «🔄 Ещё совет». Листание «📋 Все советы» (◀️/▶️) — **не считается**: рендер вызывается с `count_view=False` и пишет только `user_tips_seen` для cooldown.

### Исправленная проблема (2026-09-05)

Раньше листание «Все советы» считало каждую страницу просмотром, поэтому ачивку «Любознательный» можно было получить перелистыванием одной категории, а `total_views` переставал отражать число прочитанных советов. Исправлено флагом `count_view` в `_on_tip_viewed` / `_edit_or_send_tip`; 5 регрессионных тестов в `tests/test_tips_gamification.py`.

## Формат совета (`tips[]`)

```json
{
  "id": "tm-01",
  "title": "Правило двух минут",
  "emoji": "⏳",
  "body": "Краткое объяснение техники.",
  "tags": ["timer", "study"],
  "action": "Конкретный шаг в боте на сегодня."
}
```

- **id** — уникальный в файле (`tm-NN`, `mem-NN`)
- **title** — заголовок (жирный в Telegram)
- **emoji** — опционально, иначе emoji категории
- **body** — основной текст
- **tags** — `timer`, `flashcards`, `quiz`, `memory`, `plan`, `focus`, `study` (для фильтрации в будущем)
- **action** — строка «Попробуй сегодня: …»

## Ссылки (`links[]`)

```json
{
  "id": "link-01",
  "title": "Название для кнопки",
  "url": "https://..."
}
```

## Fallback

Если JSON отсутствует, бот читает legacy `.txt` в корне проекта (`timemanagement.txt`, `memoryretention.txt`, `links-to-productivity-material.txt`).
