# Английский язык — учебные материалы

**Doc sync:** 2026-05-25.

Предмет **уже подключён** в `SUBJECT_IDS` (`locale_bot.py`) / `SUBJECTS` (`bot.py`) — регистрировать код заново не нужно. Эта папка — для подготовки контента.

## Папка `source/`

Сюда кладите **исходные файлы** с материалами (PDF, DOC/DOCX, TXT и т.п.). Бот их напрямую не читает — это черновое хранилище для ваших материалов.

## Дальнейшая обработка

Когда материалы будут готовы, их нужно оформить в форматах бота (см. общий `study_materials/README.md`):

- `mcq.txt` — тесты с вариантами ответов
- `flashcards.txt` — карточки «термин || определение»
- `tasks/` — задания (`task-NN.json`, при необходимости `task-NN.png` или `text_only`)

При необходимости добавьте `diagnostic/default.json`, `topics.json`, `situational/` и другие файлы по [общему README](../README.md).
