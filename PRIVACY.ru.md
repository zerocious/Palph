## 2. Какие данные мы собираем

Все данные собираются в ходе вашего взаимодействия с Ботом внутри Telegram.
Мы **не** запрашиваем, не храним и не обрабатываем: ваш телефон, email,
реальное имя, платёжную информацию, точную геолокацию, фото, список
контактов, а также сообщения, отправленные вами в другие чаты Telegram.

### 2.1 Идентификаторы, получаемые от Telegram

Когда вы отправляете сообщение или нажимаете кнопку, Telegram передаёт
Боту следующие сведения. Мы сохраняем только поля, отмеченные **[хранится]**:

- **Telegram user ID** *(числовой)* — **[хранится]** — используется как
  первичный ключ вашей учётной записи. Не может быть изменён вами.
- **Telegram @username** *(если у вас есть публичный handle)* — **[хранится]**
  — кешируется, чтобы другие пользователи могли добавлять вас в друзья по
  @handle. Обновляется при каждом взаимодействии; если вы удалите свой
  @username, при следующем взаимодействии он будет очищен.
- **Language code** *(язык интерфейса Telegram, например `ru`)* —
  **[хранится]** — записывается один раз, в аналитическом событии
  `user_registered`.
- **Chat ID** — **[хранится]** — входит в ключ состояния незавершённого
  диалога (`fsm_storage`, см. §2.3). В приватном чате совпадает с вашим
  user ID.
- **Имя, фамилия, message ID** — *не сохраняются*, **кроме** случая, когда
  вы пишете свободное сообщение администраторам: такая запись в
  `messages.log` содержит ваши имя и фамилию из Telegram и message ID
  (см. §2.2 и §2.4).

### 2.2 Данные, которые вы предоставляете явно

- **Часовой пояс** (например, `Europe/Moscow`) — выбирается из предустановленного
  списка в Настройках.
- **Язык интерфейса** (`ru` или `en`).
- **Время напоминаний** (ЧЧ:ММ для утреннего и вечернего напоминания,
  плюс переключатели вкл/выкл).
- **Пользовательские флэш-карты** — пары «термин — определение», созданные
  вами. До 100 на предмет.
- **Пользовательские задачи** — текст задачи, принимаемые ответы и
  опциональная подсказка, импортируемые из загруженного вами `.txt`-файла.
- **Имя и кастомизация питомца** — строка имени, цвет, аксессуар,
  выбранные вами для цифрового питомца.
- **Свободные сообщения администраторам** — когда вы пишете сообщение,
  адресованное оператору Бота (не команду), оно дописывается в файл
  `messages.log` (см. §2.4) **вместе с вашим Telegram user ID, именем и
  фамилией из Telegram и message ID** и пересылается всем администраторам.
  Текст сообщения обрезается до 4096 символов.

### 2.3 Данные, формируемые в процессе использования Бота

- **Учебные сессии** — время начала, длительность (1–120 минут), монеты,
  опциональная оценка эмодзи (1–4).
- **Прогресс по квизам / MCQ / задачам / флэш-картам** — для каждого
  элемента: хеш содержимого, количество попыток, количество правильных
  ответов, время последнего просмотра, параметры алгоритма SM-2 (ease
  factor, interval).
- **Достижения** — прогресс и статус выполнения по фиксированному каталогу.
- **Стрик** — текущая последовательность дней подряд и флаг «занимался
  сегодня».
- **In-bot монеты** — виртуальная валюта (не имеет реальной денежной
  стоимости).
- **Уровень и XP питомца**, **инвентарь купленных предметов**, временная
  метка последнего «excited».
- **Очки лидерборда** — еженедельные суммы по типам (время / задачи / квизы
  / карты), используются для еженедельного rollover'а.
- **Записи freeze стрика** — когда вы купили freeze и какой день он
  «закрыл».
- **Отношения дружбы** — pending-заявки в друзья (from/to user IDs) и
  подтверждённые дружбы (пары user IDs). Видимы двум участвующим
  пользователям.
- **Friend invite tokens** — короткоживущие (3 дня) токены, используемые
  в deep-link'ах вида `t.me/<bot>?start=friend_<token>`.
- **История просмотров советов** — какие советы продуктивности вы уже
  видели (per-tip), какой совет дня был выбран для вас, общее число
  просмотров советов и был ли начислен сегодняшний coin-reward.
- **Журнал событий** — append-only таблица аналитических событий
  (например, `session_completed`, `settings_changed`, `tip_viewed`,
  `reminder_sent`). Каждая запись содержит ваш Telegram user ID, имя
  события, JSON-объект свойств и временную метку. Используется
  исключительно оператором Бота для агрегированной продуктовой аналитики.
  События **не** содержат введённый вами свободный текст — **за одним
  исключением**: событие `pet_renamed` сохраняет имя, которое вы дали
  цифровому питомцу, обрезанное до 20 символов.
- **Состояние незавершённого диалога** (`fsm_storage`) — пока вы находитесь
  внутри мастера (идёт таймер, сессия квиза, добавление друга,
  переименование питомца), Бот хранит текущий шаг и его рабочие данные,
  чтобы они пережили перезапуск. Ключ записи содержит ваши chat ID и
  user ID. Очищается по завершении мастера и при удалении аккаунта.

### 2.4 Операционные логи

- **Лог приложения** (`bot.log`) — текстовый лог операционных событий
  (ошибки, тики планировщика, вызовы команд, результаты рассылок).
  Может содержать ваш Telegram user ID, chat ID и имена команд. Введённый
  вами текст в него не попадает. Хранится столько, сколько ротация
  позволяет (~25 МБ общий объём ≈ дни/недели активности).
- **Лог обращений в поддержку** (`messages.log`) — append-only файл, одна
  JSON-запись на каждое свободное сообщение администраторам: временная
  метка, ваш Telegram user ID, имя и фамилия, message ID и текст сообщения.
  Автоматически не ротируется и **не** очищается командой
  `/delete_account` (она стирает только базу данных) — для удаления этих
  записей напишите на адрес из §13.
- **Бэкапы базы данных** — ежесуточные снапшоты SQLite, создаются
  автоматически. Хранятся **30 дней** по умолчанию; старше — удаляются
  автоматически.

## 5. Кому мы передаём данные

Мы **не передаём** данные третьим сторонам в коммерческих, маркетинговых
или профайлинговых целях. В частности:

- Мы **не продаём**, не сдаём в аренду и не торгуем вашими данными.
- Мы **не используем** сторонние сервисы аналитики (Google Analytics,
  Amplitude, Mixpanel и т.п.). Вся аналитика рассчитывается локально из
  собственной БД Бота.
- Мы **не интегрируем** рекламные сети.

Существуют три неизбежных стороны, участвующих в работе Бота:

1. **Telegram Messenger Inc.** — транспорт сообщений. Используя Бота
   внутри Telegram, вы также подчиняетесь Политике конфиденциальности
   самого Telegram (<https://telegram.org/privacy>). Мы не контролируем,
   что и где хранит сам Telegram.
2. **Хостинг-провайдер** сервера, на котором работает Бот. Провайдер
   имеет доступ к зашифрованному диску, где находится SQLite-база, но
   не имеет application-level доступа к вашим данным.
3. **Другие пользователи Бота** *(только для функции друзей)* — когда
   вы принимаете заявку в друзья, другой пользователь видит ваш Telegram
   @username, ваш weekly-счёт в лидерборде и ваш стрик.

## 8. Ваши права

### По 152-ФЗ (ст. 14)

- Получить сведения, касающиеся обработки ваших ПДн (оператор, цели
  обработки, объём, источники, сроки).
- Требовать **уточнения, блокирования или уничтожения** ПДн в случае их
  неполноты, неточности или утраты актуальности.
- **Отозвать согласие** на обработку ПДн.
- Обжаловать действия оператора в **Роскомнадзоре**
  (<https://rkn.gov.ru/treatments/ask-question/>) или в суде.

### По GDPR (Art. 15–22)

- **Право на доступ** (Art. 15) — получить копию всех данных о вас.
- **Право на исправление** (Art. 16).
- **Право на удаление / «право быть забытым»** (Art. 17).
- **Право на ограничение обработки** (Art. 18).
- **Право на переносимость данных** (Art. 20) — получить ваши данные в
  структурированном, машиночитаемом формате.
- **Право на возражение** (Art. 21).
- **Право отозвать согласие** (Art. 7(3)).
- **Право на подачу жалобы** (Art. 77) — в национальный надзорный
  орган ЕС.

### Как воспользоваться правами

**Удаление аккаунта (Art. 17 / 152-ФЗ ст. 14):** отправьте в Боте команду
`/delete_account`. После подтверждения все данные в активной БД — учётная
запись, прогресс, события, дружбы, питомец, очки лидерборда и состояние
незавершённого диалога — удаляются сразу. Не покрываются два файловых
хранилища: ротируемый лог приложения (`bot.log` — исчезает при ротации в
течение дней/недель) и лог обращений в поддержку (`messages.log`, если вы
когда-либо писали администраторам). Для удаления последнего напишите на
адрес из §13. Бэкапы БД могут содержать ваши данные ещё до 30 дней, затем
удаляются автоматически (см. §7).

**Остальные права** (доступ, исправление, переносимость, возражение и т.д.):
напишите на **maksim.frantsov@yandex.ru** с любого адреса, указав ваш
Telegram user ID (его можно увидеть, отправив `/start` Боту). Мы ответим
в течение **30 календарных дней** (GDPR Art. 12(3), 152-ФЗ ст. 20).
Реализация прав бесплатна.

Главный администратор не может удалить себя через `/delete_account` —
сначала смените `MAIN_ADMIN_ID` в `.env`, если нужно удалить этот аккаунт.

## 10. Безопасность

- БД представляет собой локальный SQLite-файл на сервере оператора,
  доступный только через права файловой системы ОС.
- Бэкапы хранятся на том же сервере.
- Административные команды Бота защищены проверкой Telegram user ID;
  выполнять их может только оператор и явно добавленные администраторы.
- Применяется rate limiting (30 действий / 60 секунд на пользователя)
  для защиты от abuse'а.
- Мы **не шифруем** БД at rest на текущий момент. Если это критично для
  вашего сценария — не сохраняйте чувствительную информацию в
  пользовательских флэш-картах / задачах / сообщениях администраторам.

В случае утечки персональных данных, способной создать высокий риск для
ваших прав, мы уведомим затронутых пользователей без неоправданной
задержки (GDPR Art. 34) и Роскомнадзор — в течение **24 часов** с
момента обнаружения подтверждённого инцидента (152-ФЗ ст. 21 п. 3.1),
а европейский надзорный орган — в течение **72 часов** (GDPR Art. 33).
