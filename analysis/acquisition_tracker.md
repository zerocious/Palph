## Как считать activation по каналу

Palph пока не имеет UTM в deep links (кроме friend invite). Для MVP:

1. **По дате поста:** сравни `new_today` из `/dau` в день поста ±1 день.
2. **По опросу:** спроси в комментариях «откуда узнали?».
3. **По friend invite:** считай `friend_added` events с token source.
