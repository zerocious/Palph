# Palph для Windows

Desktop-клиент к тому же аккаунту, что и Telegram-бот: монеты, стрик,
питомец и Pomodoro-таймер общие с чатом. Приложение — тонкий UI поверх
HTTP API бота (`api.py` в корне репозитория), своей базы у него нет.

## Что уже умеет

- вход по одноразовому коду из бота (`/link_app`), без паролей;
- профиль: питомец с настроением, монеты, стрик, число сессий;
- Pomodoro-таймер на 25/45/60 минут с системным уведомлением Windows —
  время считает сервер, поэтому засчитанные минуты нельзя «намайнить»,
  а закрытое приложение не теряет запущенную сессию;
- список достижений с прогрессом;
- «Отключить» — отзывает токен только этого устройства.

## Стек

Tauri 2 (Rust-обвязка + системный webview) + React 19 + TypeScript,
сборка Vite. Стили — обычный CSS с токенами темы, светлая и тёмная
подхватываются из системы.

```
src/
  api.ts          типизированный клиент api.py — типы зеркалят ответы сервера
  storage.ts      адрес сервера и токен устройства в localStorage
  notify.ts       системные уведомления (плагин Tauri)
  format.ts       формат обратного отсчёта и русские числительные
  App.tsx         состояние: есть токен → главный экран, нет → привязка
  components/     LinkScreen, HomeScreen, TimerCard
src-tauri/        окно, иконки, права плагинов; логики здесь нет
```

## Запуск

Нужны Node 20+ и Rust (для сборки под Windows — MSVC toolchain и
WebView2, он есть в Windows 11 из коробки).

```bash
npm install
npm run tauri:dev      # окно приложения + hot-reload фронтенда
npm run tauri:build    # .msi и .exe-инсталлятор в src-tauri/target/release/bundle
npm run build          # только проверка типов и сборка фронтенда
```

На сервере должен быть поднят API бота (`API_ENABLED=1`, см. README в
корне). Адрес по умолчанию — `http://127.0.0.1:8080`; для реального
сервера впишите его в «Настройки подключения» на экране привязки.

## Чего пока нет

- флэш-карт и задач — API для них ещё не написан, в приложении их нет;
- токен лежит в localStorage webview; следующий шаг — перенести его в
  Windows Credential Manager, чтобы он не хранился на диске открытым.
